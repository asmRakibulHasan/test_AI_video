Put your background music file here, e.g. `bg-music.mp3`, then set
`musicSrc: "bg-music.mp3"` in `mergeSortCatsDefaultProps`
(src/MergeSortCatsShort.tsx) or override it in the Studio Props panel.

No file is included by default — this project renders silently until you
add one. Get royalty-free tracks from YouTube Audio Library, Pixabay Music,
or similar.
